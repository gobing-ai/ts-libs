# I1: Upgrade the dsh shim to the 0.2.x headless contract

## Goal

Move the `deepseek` shim in `@gobing-ai/ts-ai-runner` from the dsh 0.1.5 positional-only headless surface to the dsh 0.2.x headless contract: NDJSON events with `--json`, resume with `--session-id`, and fixed noninteractive permissions. Downstream Spur (feature B81, task 1456) can then resume dsh sessions and read structured run events. This supersedes parent feature I's R2/R3 degrade behavior; I's other scope (registry, importer) is unchanged.

Evidence base: dsh 0.2.2-rc.1 installed (`dsh --profile headless --help`); source `~/xprojects/spur-new/vendors/deepseek-harness` (`@deepseek-ai/dsh-headless` 0.2.3-alpha.2, commit 4b399c39a6, 2026-11-22), `packages/bundle/headless/{README.md,src/startup.ts,src/index.ts,src/json-stream.ts}`.

## Scope

- In:
    - `dshShim.getPromptCommand`: `dsh --profile headless [--json] [--session-id <id>] --permission-mode workspace-write --approval-policy never -- <input>`
    - `deepseek` row in `AGENT_SESSION_CAPABILITY`: resume-by-id and structured output true; session-dir and persistent stdin stay false, with notes
    - Recorded `--json` fixtures under `packages/ai-runner/tests/fixtures/dsh/` that tie exit status to `final.reason.kind`
    - Shim unit tests replacing task 0066's degrade assertions
- Out:
    - NDJSON event parsing in ai-runner
    - `--add-dir` and any new `PromptOptions` permission/grant field (deferred until Spur task 1458 needs it)
    - `--model` (no headless flag at 0.2.2-rc.1)
    - Importer changes, registry/order changes, version bump/publish (operator-run)
